# 项目实践记录

这里会放真实项目的设计和复盘。每个项目可以新建一个文件夹，按下面的问题记录；没有证据的结论标为待验证。

第一个案例：[ChronoDraft：从保存版本理解现有设计](chronodraft/保存与恢复的设计复盘.md)。

## 记录模板

```text
项目名称：
记录日期：

1. 想解决的问题：谁遇到了什么问题？
2. 第一版目标：用户能完成哪一条完整流程？怎样验收？
3. 已知约束：平台、时间、预算、已有经验、数据与安全要求。
4. 当时不懂的问题：需要调查哪些概念或成熟做法？
5. 方案比较：考虑过哪些选择？事实依据和取舍是什么？
6. 最终决定：架构、技术栈、范围，以及由谁确认的业务取舍。
7. 实现与验证：实际做了什么？正常、边界、失败路径结果怎样？
8. 复盘：哪些判断正确，哪些需要修正，下一次会怎样做？
```
